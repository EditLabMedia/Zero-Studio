# Zero Studio - Photography & Videography Agency

A cinematic, ultra-professional, fully responsive website for Zero Studio - a premium photography and videography agency.

## 🎬 Features

- **Responsive Design** - Works flawlessly on all devices
- **Cinematic Animations** - Smooth Framer Motion animations throughout
- **Dark Theme** - Premium dark aesthetic with purple/cyan accents
- **Portfolio Masonry** - Beautiful grid with images, GIFs, and videos
- **Booking Form** - Full validation with success modal
- **Team Showcase** - Meet the talented Zero Studio team
- **Parallax Effects** - Stunning depth and movement
- **Glass Morphism** - Modern UI with frosted glass effects

## 🛠️ Tech Stack

- **React 18** - Modern UI library
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Powerful animation library
- **Lucide React** - Beautiful icon system
- **Vite** - Lightning-fast build tool

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
